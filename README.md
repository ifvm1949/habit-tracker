### 🇨🇳 中文说明

#### ✨ 特点
- 🪶 **极致轻量**：App 安装包仅 12MB，不占手机内存。
- 🎨 **自定义外观**：默认黑白极简风，支持将背景图替换为任何你喜欢的图片，自带毛玻璃特效。
- 🔒 **登录可选**：不强制注册，无需留手机号。打卡数据默认保存在本地，保护隐私。
- 📊 **数据统计**：支持周报/月报趋势图、日历视图、连续打卡天数统计。
- 🚫 **纯净无广**：没有任何广告和繁杂的社交功能。

#### 💡 怎么用？
**在 App 中**：
打开软件 -> 点击“开始你的第一个” -> 设置习惯名称和图标 -> 每天点击打卡。

###  English Intro

#### ✨ Features
- 🪶 **Ultra-Lightweight**: The app is only 12MB.
- 🎨 **Customizable UI**: Default clean black/white theme. Supports custom background images with a glass effect.
- 🔒 **Optional Login**: No forced sign-up. Data is stored locally for privacy.
- 📊 **Data Visualization**: Weekly/Monthly reports, calendar, and streaks.
- 🚫 **Ad-Free**: No ads, no distracting social features.

#### 💡 How to use
**In the App**:
Open the app -> Tap "Start your first habit" -> Set name & icon -> Tap to check in daily.
